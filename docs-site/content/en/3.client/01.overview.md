The **Cubiq Client** is the client mod that comes with the Cubiq Launcher. It adds a HUD, PvP and comfort modules, a minimap and world map, redstone tools, performance options, emotes, capes, a wardrobe and a social chat – all in the same redstone look as the launcher. Everything is set up in one place: the **Cubiq menu**.

## Supported versions

| Loader | Minecraft versions |
| --- | --- |
| Fabric (also used for Quilt) | 1.14.4 – 26.3 |
| Forge | 1.7.10, 1.8.9 – 1.12.2, 1.13.2, 1.14.4 – 26.3 (not every minor version) |
| NeoForge | 1.20.2 – 26.3 |

Vanilla instances get the Cubiq Client too when the **Cubiq optimization** is on in the instance settings – the launcher then runs the game with Fabric under the hood.

::note
Not every feature exists in every Minecraft version. The biggest gaps are on **1.7.10** and **1.13.2**, which have the Cubiq menu, HUD, zoom, maps, redstone tools, notes, wardrobe, accounts and clips, but no Cubiq online features (capes, emotes, social chat), no performance category and no freelook. **Forge 1.14.4** also misses modules that need deeper game hooks. Every page of this documentation names its version limits.
::

## How the Cubiq Client gets into your game

::steps
### Create or open an instance
The launcher adds the Cubiq Client by itself when a build exists for the instance's Minecraft version and mod loader. You don't download anything.

### Check the switch
In the instance settings under **Installation** there is a **Cubiq Client** switch. Turn it off if you want to play without it – it then stays off for that instance.

### Start the game
The client updates itself: the launcher checks for a newer Cubiq Client before starting and installs it automatically.
::

::tip
When you install a modpack, the launcher asks once whether you want it **with** or **without** Cubiq Client. Packs that already bring their own client, minimap or HUD mods get "without" preselected.
::

## Open the Cubiq menu

Press :kbd{value="Right Shift"} in game. On the Cubiq title screen you can also click **Cubiq Menu** or **Cubiq Settings** in the bar on the right.

If nothing happens, check the key:

::steps
### Open the controls
Go to **Options → Controls → Key Binds** and scroll to the category **Cubiq Client**.

### Find "Open Cubiq menu"
The default is :kbd{value="Right Shift"}. If another mod uses the same key, Minecraft marks it red – pick a free key.

### Use the search
From 1.8.9 on, the key binds screen has a search box. Type `conflict` to see every key that is used twice.
::

## The introduction

The first time you start the Cubiq Client, a short introduction with four steps appears:

1. **Language and look** – language, theme and accent colour.
2. **Performance** – "Pretty" or "Max FPS", frame limit and VSync.
3. **Key bindings** – the most important Cubiq keys. Keys that clash with Minecraft or other mods are highlighted and can be changed right there.
4. **Module pack and HUD** – a starting point for your play style.

You can skip it at any time. It shows up once per Cubiq account, and you can start it again in the Cubiq menu under **Presets → Restart introduction**. The introduction is not available on 1.7.10 and 1.13.2.

## Cubiq online features

Capes, badges, emotes, the social chat, settings sync and bug reports use the Cubiq services. They need:

- the Cubiq services switched on in the launcher (**Settings → Privacy**),
- a Microsoft account (offline and demo accounts can't sign in),
- the module **Cubiq Online Features** switched on in the Cubiq menu.

The client signs in with your Minecraft account, just like when you join a server.

## Report a bug from the game

Something doesn't work? Open the Cubiq menu and click **Report bug**. Write a title and what happened, and choose what to attach: Cubiq Client version, Minecraft version and loader, mod list, a log excerpt and a screenshot. Before sending you see exactly what goes out – the log is cleaned of tokens, UUIDs, names, IP addresses, email addresses, user paths and chat lines. After sending you get the issue number and can open it in the browser.

::warning
Bug reports are published in the public issue tracker on the website. Don't write private data into the title or description.
::
