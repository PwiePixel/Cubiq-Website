Der Cubiq Launcher hält sich selbst aktuell. Neue Versionen sind signiert, laden im Hintergrund, während du spielst, und werden beim Neustart installiert.

## Launcher aktualisieren

::tabs
:::tabs-item{label="Windows / AppImage" icon="i-lucide-monitor"}
1. Gibt es eine neue Version, lädt der Launcher sie im Hintergrund. Das Aufgaben-Panel zeigt „Update wird im Hintergrund geladen“.
2. Sobald sie bereit ist, erscheint in der Titelleiste der Knopf **Neu starten zum Aktualisieren**.
3. Klick darauf. Du siehst kurz „Wird aktualisiert – startet gleich neu …“, dann startet die neue Version. Laufende Spiele laufen weiter.

Schlägt ein Update fehl, zeigt die Titelleiste den Grund und bietet **Update erneut versuchen** oder **Installer laden** an.
:::

:::tabs-item{label="Linux-Pakete" icon="i-lucide-terminal"}
Die Pakete .deb, .rpm und aus dem AUR aktualisiert deine Paketverwaltung. Der Launcher sagt dir nur Bescheid: „Update … verfügbar“, mit einem Link zum Release.

- Arch (AUR): `yay -Syu` oder `paru -Syu`
- Debian/Ubuntu: die neue `.deb` herunterladen und mit `sudo apt install ./Cubiq-Launcher_<version>_amd64.deb` installieren
- Fedora/openSUSE: die neue `.rpm` mit `dnf` bzw. `zypper` installieren
:::
::

## Der Cubiq Client aktualisiert sich selbst

Der Cubiq Client hat einen eigenen, signierten Update-Kanal und bekommt Korrekturen ohne neue Launcher-Version. Er aktualisiert sich beim nächsten Spielstart selbst. Die aktuelle Version des Cubiq Clients steht unten in den Einstellungen.

## Was ist neu

Nach einem Update zeigt der Launcher einmal **Neu in Version …** mit allem, was die neue Version mitbringt:

- das **Update-Banner** mit dem Namen des Updates und seinem eigenen kleinen Bild,
- eine **Galerie** mit Screenshots der Neuerungen – ein Klick vergrößert ein Bild, mit den Pfeiltasten blätterst du weiter,
- die **Hinweise** zum Update, für Spieler geschrieben,
- **Release auf GitHub ansehen** und **Alles klar** zum Schließen.

Hast du ein paar Updates übersprungen? Dann sammelt „Neu in Version …“ alle: Die Versions-Knöpfe unten links (zum Beispiel **v0.3.3**, **v0.3.2**, **v0.3.1**) wechseln zwischen den Updates, so verpasst du nichts.

![„Neu in Version“ nach mehreren Updates: Banner, Screenshot-Galerie und unten die Versions-Knöpfe](/shots/launcher/update-news.de.webp)

::note
Die Hinweise gibt es auf Englisch und Deutsch. Ist der Launcher auf eine andere Sprache eingestellt, siehst du die englischen Hinweise mit einem kurzen Vermerk darüber.
::

### Ein bewegtes Bild für jedes Update

Jedes Update hat in seinem Banner eine eigene kleine, bewegte Pixel-Art-Szene – vom allerersten Update bis zum neuesten: Cubi, der grüne Würfel aus dem Cubiq-Logo, auf einer schwebenden Grasinsel neben etwas, das zum Update passt. Das Bild von 0.3.0 zeigt zum Beispiel Cubi mit den Polarlichtflügeln, umringt von seinen neuen Begleitern. Die Szenen laufen ruhig neben dem Titel und laden schnell, auch auf langsameren PCs.

Magst du es lieber ruhig? Mit **Animationen reduzieren** unter **Einstellungen → Aussehen → Animationen** siehst du stattdessen das stehende Bild jeder Szene. **Wie Windows/System** macht dasselbe, wenn Animationen in Windows oder auf deinem Desktop ausgeschaltet sind.

## Die Update-Karte auf der Startseite

Auf der Seite **Start** wartet unter „Weiterspielen“ das neueste Update als Karte auf dich: sein Banner mit dem bewegten Bild, der Name des Updates, die Schlagzeilen der Hinweise als kleine Chips, kleine Vorschaubilder der Screenshots und **Beitrag lesen**.

- Ein Klick auf das Banner oder auf **Beitrag lesen** öffnet den ganzen Beitrag – dieselbe Ansicht wie „Neu in Version …“.
- Ein Klick auf ein Vorschaubild öffnet den Beitrag direkt bei diesem Screenshot. Hat ein Update mehr Bilder, öffnet ein kleines Abzeichen wie **+2** den Rest.
- Das **×** in der Ecke (**Bis zum nächsten Update ausblenden**) blendet die Karte aus. Mit dem nächsten Update ist sie wieder da.

![Die Update-Karte auf der Startseite mit dem bewegten Bild des Updates, seinen Schlagzeilen, Vorschaubildern und „Beitrag lesen“](/shots/launcher/update-card.de.webp)

Das Update erscheint außerdem unter **Neuigkeiten** auf der Startseite. Unter **Alles** steht vom Launcher nur die neueste Version zwischen den anderen News; der Filter **Launcher** listet jedes Update und – mit eingeschalteten Cubiq-Diensten – die News des Cubiq-Teams.
